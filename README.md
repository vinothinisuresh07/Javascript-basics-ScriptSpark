## How to run the code

**Option 1: Browser (easiest)**
Copy the code, open your browser, press `F12`, go to the **Console** tab, paste it and press Enter.

**Option 2: VS Code**
1. Download this repo (green **Code** button → **Download ZIP**) and open the folder in VS Code.
2. Open the `.js` file.
3. Open the terminal (**Terminal → New Terminal**) and run: `node index.js`

> Option 2 needs [Node.js](https://nodejs.org) installed. If you don't have it, use Option 1.
